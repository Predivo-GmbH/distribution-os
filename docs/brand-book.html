07

Guidelines

Rules for consistent application of the Distribution-OS brand across all surfaces.

Do

  • Use #0a0a0a as page background on public pages
  • Use white buttons for primary CTAs on dark backgrounds
  • Use indigo (#6366F1) as the accent for links, focus rings, active states
  • Use Inter for all UI text, JetBrains Mono for data
  • Keep 44px minimum touch targets on all interactive elements
  • Use glassmorphism cards (white/3-4% + backdrop-blur)
  • Use scroll-reveal animations with staggered delays
  • Use step indicator dots for multi-step flows
  • Use rounded-2xl (16px) for auth cards, rounded-lg (8px) for buttons

Don't

  • Don't use pure white (#fff) backgrounds on public pages
  • Don't use pill-shaped buttons for primary CTAs (use 8px radius)
  • Don't use shadows on cards in light mode — use borders instead
  • Don't hardcode hex colors in components — use CSS variables or Tailwind
  • Don't use animations that require framer-motion or other libraries
  • Don't use text smaller than 11px anywhere
  • Don't use more than 2 font weights on a single card
  • Don't use engine colors for non-engine elements
