Required Architectural Changes

Storage: localStorage-First

localStorage is source of truth. Supabase is optional fire-and-forget sync. Data lost on device switch.

↓ Must become ↓

Storage: Supabase-First

Supabase is source of truth. localStorage is read-through cache for offline access. Sync queue for pending mutations.

Auth: Optional

PasswordGate pre-launch. Supabase Auth optional (skipped if env vars missing). App works without any user identity.

↓ Must become ↓

Auth: Mandatory

Supabase Auth required on all routes. Hard-fail if not configured. PasswordGate removed entirely.

API: Direct Browser Calls

Browser calls Anthropic API directly with key in headers. 'anthropic-dangerous-direct-browser-access' header.

↓ Must become ↓

API: Server-Side Proxy

Supabase Edge Function proxies all AI calls. Client sends prompts only. Server manages keys, quota, and logging.

Scheduler: Browser-Only

setInterval 60s tick. Stops when tab closes. No catch-up, no locking, no timezone awareness.

↓ Must become ↓

Scheduler: Server-Side + Browser

Server-side cron (pg_cron or external) as primary. Browser scheduler as fast-path. Distributed locking. Timezone-aware.
