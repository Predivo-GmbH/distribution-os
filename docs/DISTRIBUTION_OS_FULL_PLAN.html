  • Billing: Stripe integration, tier gate enforcement
  • API Keys: Edge function proxy, BYOK support, no client-side exposure
  • Scheduler: Evaluate browser-only vs server-side
  • Hardcoded values: Remove all internal references
  • Landing page: Placeholder for Sprint 10
